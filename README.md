# موقع أكاديمية البراءة التعليمية

موقع تعريفي ثابت (HTML وCSS فقط، بلا بناء ولا قاعدة بيانات) يُنشر على `https://albaraah.org`.

- `index.html` الصفحة الرئيسية، و`404.html` صفحة الرابط غير الموجود، و`styles.css` التصميم.
- `assets/` الشعارات، وأيقونة الموقع، وصورة المشاركة (1200×630).
- `robots.txt` و`sitemap.xml` لمحركات البحث.
- يُنشر على Cloudflare Pages مجاناً (بلا خطوة بناء، ومجلد الإخراج هو جذر المستودع)؛ كل دفع إلى الفرع `main` ينشر الموقع.

هذا المستودع منفصل تماماً عن نظام الأكاديمية ولا يحوي أي بيانات منه.

للمعاينة على الجهاز:

```
python -m http.server 8790 --directory .
```
